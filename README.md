Генератор регламента и тайминга спортивного мероприятия.

## Как пользоваться
1. Дважды щёлкните «Открыть генератор» в этой папке — откроется страница в браузере.
2. Укажите дату, отметьте виды спорта и дистанции (или добавьте свою), нажмите «Создать регламент».
3. Нажмите «Сохранить файл в папку» — файл появится в папке «Готовые регламенты».

Файлы программы лежат в папке «Генератор».
