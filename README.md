Генератор регламента и тайминга спортивного мероприятия.

## Как пользоваться
1. Дважды щёлкните «Открыть генератор» в этой папке — откроется страница в браузере.
2. Укажите дату, отметьте виды спорта и дистанции (или добавьте свою), нажмите «Создать регламент».
3. Нажмите «Сохранить файл в папку» — файл появится в папке «Готовые регламенты».

Файлы программы лежат в папке «Генератор».

## Онлайн и в Telegram
- Сайт: https://7772982-spec.github.io/reglament-generator/ (файл скачивается в «Загрузки»).
- Telegram-бот: @reglamentgeneratorbot. Код в папке «Бот», ключ — в `Бот/token.txt` (в репозиторий не попадает).

## Google-таблица
Бот хранит данные в Google-таблице: лист «Регламенты» (все созданные регламенты),
«Дистанции» (список видов спорта и дистанций — его можно править прямо в таблице)
и «Состояние бота» (незаконченные разговоры). Генератор на компьютере тоже добавляет строку в таблицу.
Таблица подключается скриптом `Бот/google-script.gs` (Расширения → Apps Script → веб-приложение);
ссылка на него хранится в `Бот/sheets.json` и в репозиторий не попадает.

## Перезапуск бота
Дважды щёлкните «Перезапустить бота» в папке «Регламенты». Нужно, например, после правки листа «Дистанции».
